With non-null gate, forward-only -> +1, backward-only -> -1, equal flags -> 0. With null gate, forward=true -> 0 and forward=false -> -1; the backward flag is not used on that arm. The source now preserves both gate branches.
- `b([Z)D`, original 50 instruction rows and 7 handlers: read the same gate first, then left. With non-null gate, left-only -> -1, right-only -> +1, equal flags -> 0. With null gate, left=true -> 0 and left=false -> +1; the right flag is not used on that arm. The source now preserves both gate branches.
- Original constructor descriptor `()V` initializes the candidate field read by `c(List)` with eight four-boolean vectors, in order: forward, backward, left, right, forward+left, forward+right, backward+left, backward+right.
