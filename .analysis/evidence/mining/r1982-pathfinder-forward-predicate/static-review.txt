Confirmed source defect and repair
The original reads the shared gate and the "forward" input before branching. If the gate is non-null, a false input returns false and a true input continues into the geometry checks. If the gate is null, the input getter is still evaluated, but the gate branch bypasses this early return. The managed source had negated the input result, reversing the non-null-gate condition. R1982 removes that negation and leaves evaluation order and subsequent logic unchanged.
